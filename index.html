PF1ABOUT ME

      
My name is Chris Sena, and I go by SenaDev2023 on GitHub. By day I'm a full stack developer at hubley, building on SharePoint and TypeScript. The rest of the time I work in C++ on the layer most people never see: middleware, serialization, and the code other code depends on.

      
I didn't start in software. I was a Marine radio chief, then a water utility SCADA operator, where my first production terminal was an IBM z/OS mainframe and I traced customer payments through COBOL before I ever wrote a line of C++. That's why this site looks like a green screen.

      
Everything here is out in the open. The site's source lives in a Git repository, so every edit is on the record, and my working notes on open-source fixes are in open-source-fixes.
